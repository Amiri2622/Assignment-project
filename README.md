
# Web Test Automation Project

**Java | Selenium WebDriver | Cucumber BDD | Maven**

## Project Overview

This is a software test automation project originally developed in 2023 as part of my software testing studies.

The project demonstrates browser automation and behavior-driven testing using Java, Selenium WebDriver, and Cucumber.

## Technologies Used

- Java
- Selenium WebDriver
- Cucumber BDD
- Gherkin
- Apache Maven
- Google Chrome / ChromeDriver

## Test Scenario

The project includes an automated login scenario for the nopCommerce administration demo application.

The Gherkin feature file describes these steps:

1. Navigate to the login page.
2. Enter an email address and password.
3. Click the login button.
4. Check the login outcome.

## Project Structure

- `src/test/java/Features5/` - Gherkin feature files
- `src/test/java/JavaFoldersnextstep5/` - Selenium step definitions
- `src/test/java/TestRunerecucumber5/` - Cucumber test runner
- `pom.xml` - Maven project configuration
